# E001–E010 research checkpoint

**Version 0.1.0-research — active research, not deployment-ready.**

This checkpoint consolidates ten completed experiments on unseen-question mathematical-misconception detection and simulated human-review routing. It preserves the negative classifier, automation-threshold and meaningful-review-gain results.

Included:

- An evidence-linked research report, experiment index and concise README.
- Four reproducible aggregate-only figures, with all plotted values and source fingerprints.
- A separate hash-locked, non-root Docker verification environment and public-checkout CI.
- Historical-preservation and publication checks, plus repository citation metadata.

No new model, threshold, split or research experiment was run for this release. E001–E010 scientific records remain unchanged. No raw data, row-level outputs, fitted models or credentials are included.

The core finding is not deployment success: lexical and frozen-embedding models fail to beat frequency under held-question evaluation; improved reliability ranking does not deliver an admissible automation policy, and E010 misses its primary meaningful-gain criterion. Only 15 middle-school questions underpin these results.

Fresh Docker verification covers synthetic tests and public aggregate checks, **not a fresh reproduction of every historical model**. The original full modeling environment remains incompletely locked. Historical reporting gaps, retrospective E004/E005 publication and the legacy Brier correction remain explicit.

See [the research report](RESEARCH_REPORT.md), [reproduction guide](REPRODUCTION.md) and [release audit](RELEASE_AUDIT_2026_10.md).
